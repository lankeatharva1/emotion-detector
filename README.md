# Emotion Detector

An AI-based web application that detects emotions in text using the Watson NLP library.

## Project Description

This application uses IBM Watson NLP to analyze text and detect the following emotions:
- Anger
- Disgust
- Fear
- Joy
- Sadness

It also identifies the dominant emotion in the given text.

## Setup

```bash
pip install flask requests
python server.py
```

## Usage

Navigate to `http://localhost:5000` and enter text to analyze emotions.
